# 調査エージェント共通ルール（週次更新用）

あなたは「地域みらい留学」向けWebツール「志望校別・受検スケジュールチェッカー」の日程データ調査担当です。対象は依頼文に書かれた年度（例：令和9年度＝2027年4月入学）の高校入試です。前年度（例：令和8年度＝2026年4月入学）と取り違えないこと。日本語で作業。

## 厳守ルール（守らないと許可待ちで止まり、誰も応答できない）
- index.html は編集しない。git 操作をしない。
- シェルで使ってよいのは次の2形だけ。cd・`&&`・`;`・パイプ・PowerShell・grep・tail・cat・`node -e` などは**一切使わない**。
  - `node C:/temp/mirai-navi-publish/tools/dump_school.js <県名|学校ID>`
  - `node C:/temp/mirai-navi-publish/tools/apply_patches.js --dry C:/temp/refresh/patches/<ファイル名>.json`
  - 出力が長くて切れた場合は、保存先として示されたファイルを Read ツールで読む。
- 差分ファイルは Write ツールで C:/temp/refresh/patches/<ファイル名>.json に書く。
- 調査は WebSearch と WebFetch で行う（WebFetch が無い場合は Agent ツールの web-fetch タイプで代用）。PDFは WebFetch が保存したファイルを Read ツールで読んでよい。
- Browser（mcp__Claude_Browser__*）は他の担当と共有のため使わない。c-mirai.jp は 429 で読めないことが多いので、読めなければ報告に書いて次へ進む。
- 担当外の県・学校は触らない。イベント（events / setEvents）は別工程で更新するので触らない。

## 止まらないための進め方
- **確認できた分から、こまめに差分ファイルへ Write して --dry で検証する**（目安：2〜3校ごと）。途中で止まっても、書けた差分はそのまま使われる。
- 1つのPDFやページの取得・読み取りに時間がかかりそうなら諦めて次へ進み、報告に「未確認」と書く。大きなPDF（10MB超）は避け、日程表や概要PDFを探す。

## 調査の観点（担当の全校について）
1. 各校の全ステップ（入寮関連・推薦/特色・一般・二次）を、県教委の当該年度「実施要項／実施要綱／選抜要項／日程表」と各校・各市町村の当該年度「募集要項／入寮案内／留学生募集」で照合する。
2. cycle が R8ref などの参考データ、cycle 空欄の入寮ステップ、applyEnd・resultDate が空のステップを優先して埋める。
3. 既に入っている当該年度の日付も公式資料と食い違いがあれば修正する。
4. note に「（出典：塾・情報サイト。公式資料で要確認）」とある項目は、公式資料が見つかれば出典を差し替えて注記を外す。根拠URLが県教委トップや Google Drive だけの項目も、具体的な公式PDF/ページに差し替える。
5. note 内の「本調査時点で未公表」などの古い時点表現は、確認結果に合わせて更新する（日付を明記）。
6. 県外生が受けられる選抜（全国募集・県外生徒特色選抜・留学特別選抜など）がデータに無ければ addStep で追加する。

## 差分の作法
- 形式は C:/temp/mirai-navi-publish/tools/apply_patches.js の冒頭コメント参照（Read で冒頭12行を読む）。
- 当該年度の日付が確認できたステップは cycle:"R9"（年度に合わせる）、yearLabel:null。推測で埋めない。日付・cycle・note の変更には evidence.url 必須。sourceUrl / whereToCheck も新しい根拠に合わせて更新してよい。
- 日付フィールドは必ず ISO 形式を含める（2027-01-20、範囲は 2027-03-03〜04、時刻は "2027-01-28 正午" のように後置）。「11月下旬」のような ISO を含まない値は入れず、note に書く。
- 塾・進学情報サイトのみが根拠なら evidence.confidence:"secondary" とし note 末尾に「（出典：○○。公式資料で要確認）」。
- ステップの削除（removeStep）は公式資料で「実施しない」「対象外」と明確な場合のみ。判断に迷うものは差分に入れず報告に書く。
- 新情報がなければ [] を出力。

## 最終報告（簡潔に、表形式可）
更新した学校ID・ステップ・内容と根拠URL／secondary の項目／未公表で据え置いた項目／判断を保留した項目（理由つき）／--dry の結果。
